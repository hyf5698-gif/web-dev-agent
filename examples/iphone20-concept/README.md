# iPhone 20 独立概念页

直接打开 `index.html` 即可查看，全部样式、脚本与两张产品图均在当前目录，无构建步骤或外部素材依赖。

示例展示四个段落：产品开场、材质近景、可暂停的互动光轨、暖金与石墨配色选择。配色图片在同一画框中交叉渐变，支持中途反向切换；减少动态偏好下即时切换。字体通过本地字体栈呈现，不分发系统字体文件。

这是协作制作的样本：本地 Agent 生成方向稿；CLI 文件审批中断后，由宿主 AI 恢复并完成其余章节、图像变体、过渡和字体修订。完整过程并非全部由 Agent 自动执行。浏览器检查覆盖了桌面与手机布局、配色与流光操作、弹窗及图片加载；不保证所有浏览器或设备均有相同效果。

页面与 Apple 无关联，外观与视觉叙事为概念创作，不代表真实产品规格，没有购买或预订功能。图片为 AI 概念渲染，生成方式与提示词见 [ASSETS.md](ASSETS.md)。
