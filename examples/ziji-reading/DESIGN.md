# 字间｜已确认方向的静态网页实现

受众：喜欢文学、摄影与线下交流的年轻中文读者。主要动作：查看本月共读；次要动作为不采集、不保存、不发送信息的本地演示报名。

艺术方向：把一次共读排成一本当代文学季刊，让纸面、字形与朱红色的几何日光共同邀请读者停留。

方向已获用户确认，本轮在原有首屏、共读专题及其手机重排基础上补齐单页内容与本地功能。读书会、书籍《街道的留白》与专题文字均为虚构，页面已标明。没有真实活动时间、地点和报名服务。

延续 designId `24b18b68-3101-4db8-adc0-55ec4b67e207` 的已批准计划，DESIGN_PLAN.json 保留为方向快照。顶部状态更新为“虚构读书会 · 静态演示”。

## 字体与颜色

标题与品牌使用本地宋体族 Songti SC / STSong / SimSun；正文、导航、说明使用本地系统黑体 PingFang SC / Microsoft YaHei。宋体标题采用中等字重、约 1.35–1.6 倍行距及少量字距；避免依赖额外粗体。中文标题按完整分句断行，正文以约 25 字的行长、2 倍以上行距保持清晰。字号小的辅助文案采用黑体，标题朱红句号单独处理，减少深色字面的压迫感。不同设备实际字体会随本地字体变化，需由宿主渲染继续检查。

纸面 #f2efe7 为背景，近黑 #24251f 为正文与主要按钮，朱红 #b53e2c 用于几何主视觉、专题提示及交互强调；灰绿 #707168 用于辅助文字，#c4c2b6 为细分隔线。反馈兼有明确文字，键盘焦点显示朱红轮廓。

## 版式与视觉

桌面首屏左右近等宽：左侧标题与主动作，右侧约 440px 高原创几何图形，以圆、折页线条和“间”字形成视觉重心。主标题约 48–74px，图形与标题并重；图形在独立容器内裁切。首屏底部以细线和短句收束。

代表中段保留较小标题与密一些的专题正文、竖版书封和窄页边问题的三栏，制造观看距离和疏密变化。书封是 CSS 绘制的虚构示意，不是已出版图书。后续内容延续编辑式节奏：左右分栏的共读方式与三步清单、浅灰绿宽幅页边练习、标题配展开问答，最后用一句话和共读入口收尾，不重复首屏构图或铺设统一卡片。

主视觉、书封均为已就绪的原创 CSS 几何图形，无远程素材，无关键素材缺口。未使用或声称浏览外部参考。

## 交互与手机

“翻开本月共读”使用页内锚点；演示报名打开原生 dialog，可用按钮、Esc 或点击框外关闭；无个人信息输入、网络请求或本地存储。悬停变朱红，按下略微下移，键盘焦点可见。所有内容均静态可读。

新增页边练习的三个原创提问可循环切换，带编号与 aria-live 文本反馈，无输入框；常见问题使用原生 details/summary，支持键盘和无脚本阅读。弹窗补齐可访问名称和说明，保留原生焦点约束和关闭后返回触发按钮的行为；增加跳至共读的键盘入口。报名不设置名额或虚假提交错误，因为没有真实提交；每次打开均为本地演示确认。

手机改为单栏：刊头、标题、导语、主动作、缩小后的几何图形；中段先读专题再看书封，页边问题变成横向收尾。隐藏重复的顶栏共读链接，保留首屏主动作；不以缩小整个桌面版代替重排。

后续章节在手机上按标题、说明、步骤阅读，练习题减少强制断行，问答占满可用宽度；按钮与问答触控区域至少44px高。极窄屏首屏标题从49px适度缩小，避免完整中文分句横向溢出；平板书封缩减内边距，仍保留宋体与原配色。

仅锚点滚动与按钮颜色使用短过渡，服务定位与反馈，不自动播放。prefers-reduced-motion 下取消平滑滚动与过渡。

## 验证与剩余工作

入口为 index.html，样式与脚本均为相对路径、本地静态文件，无依赖、构建、后台或远程素材。已检查脚本语法、JSON、ID唯一性、页内锚点与本地引用。桌面与手机实际渲染由宿主提供，本轮未操作浏览器；实际字体、裁切、手机排版与弹窗键盘操作仍待宿主浏览器验证。没有真实报名服务或待接入素材；不发布、不部署。
