# 纸间 · 设计说明

## 本轮调整

- 保留结构与新增、已读、删除逻辑；主标题改为“喜欢的书，慢慢读。”，在逗号后固定换行。
- 按钮、书签、焦点及交互强调统一为墨绿 #254d40，悬停为深墨绿 #193b30。
- 品牌副标、标题角标、插图注脚、键盘提示和页脚改为自然中文，空状态角标改为“序章”。中文注脚取消斜体，手机仍限宽换行。
- 移除不存在的 agent-repair-probe.js 引用；使用内嵌 SVG 站点图标。页面无需外部资源。
- 墨绿色与中文文案版本已由宿主提供渲染截图及资源检查报告，详细复核见文末；实际交互仍待浏览器操作验证。

- 产品：单页中文阅读清单，供想整理下一本阅读计划的读者使用。初始清单为空，内容仅在当前页面会话中保留，刷新后清空。
- 主要动作：输入书名新增，切换已读 / 未读，删除条目。
- 视觉：借鉴杂志目录，以大标题、细分隔线、序号和宽松行距组织内容，不使用卡片堆叠。原创 CSS 绘制书页图形，无外部素材。
- 配色角色：米色 #f3efe5 为纸面，近黑 #25251f 为标题与正文，墨绿 #254d40 为主要按钮和强调，灰褐 #797569 为辅助文字，浅褐 #d5cdbf 为分隔线。
- 字体：标题使用本地宋体类 serif 字体，正文与按钮使用系统中文 sans-serif 字体，不加载远程字体。
- 版式：桌面为居中限宽杂志页面，页眉品牌、主视觉标题、添加表单、阅读目录、页脚依次排布。目录使用连续列表与横线。
- 交互：回车键或按钮新增，忽略纯空白输入并提供提示；每行有可访问的完成切换和删除按钮；实时更新总数与已读数量，状态变化通过 live region 提示；所有按钮支持键盘与明显焦点。
- 移动端：缩小标题和页面边距，添加表单保持可触达，长书名自动换行，列表操作按钮保持足够点击面积；尊重减少动画偏好。
